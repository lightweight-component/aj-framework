关于 DFA 敏感词过滤

将词库组织成一棵 Trie 树：相同前缀共用节点。从文本中的每个位置开始，沿着字符对应的节点向下查找，到达词尾节点就表示命中一个敏感词。

例如 app 与 apple 共用 a → p → p 这一段路径。“查找所有敏感词”会保留重叠匹配；高亮展示时合并重叠区间。当前实现逐位置匹配，耗时与文本长度和词的长度有关。
